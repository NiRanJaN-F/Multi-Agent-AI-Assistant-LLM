## Overview

Build a full-stack e-commerce store with product listings, a shopping cart, and checkout flow using Express backend and interactive HTML/JS frontend.

## Tech Stack

Node.js Express + Vanilla HTML/CSS/JS

A monolithic full-stack e-commerce architecture utilizing Node.js and Express to serve both the REST API and static frontend assets. The backend manages in-memory data persistence for products, shopping carts, and order checkouts. The frontend is built with vanilla HTML5, CSS3, and modular ES6 JavaScript for reactive client-side state management and seamless API integration.

## Implementation Plan

- Initialize Express backend with product and cart routes
- Build frontend HTML layout for product catalog and shopping cart
- Implement client-side JavaScript for cart state management and API integration
- Develop checkout flow endpoints and order confirmation handling
