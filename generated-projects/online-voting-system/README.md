# Online Voting System

> Generated by the Multi-Agent AI Software Engineering Assistant.

## Overview

Build a full-stack online voting system with voter registration, candidate listings, secure login, voting functionality, vote validation, and a live results dashboard using Express backend and an interactive HTML/JS frontend.

## Tech Stack

Node.js + Express + HTML/CSS/JavaScript (Vanilla)

This architecture implements a secure online voting system using a modular Express backend and a dynamic Vanilla JavaScript single-page frontend. In-memory data structures store users, candidates, and cast votes with strict double-voting checks enforced per session. Session-based authentication protects voting and dashboard routes, while the frontend provides real-time polling updates for the live results interface.

## Implementation Plan

- Set up Express server with JSON body parsing, session management, and in-memory storage for users, candidates, and votes.
- Implement authentication routes for voter registration, secure login, and session validation.
- Create candidate listing and vote submission endpoints with validation to prevent double-voting.
- Build a live results dashboard endpoint and an interactive frontend with vanilla JS for seamless user interaction.
