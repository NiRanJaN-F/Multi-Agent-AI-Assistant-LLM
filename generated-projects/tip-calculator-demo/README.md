## Overview

## Tech Stack

Vanilla HTML5, CSS3, JavaScript (ES6+)

This architecture follows a client-side only approach, leveraging vanilla HTML5, CSS3, and ES6+ JavaScript for maximum performance and zero backend dependencies. State management is handled through a centralized JavaScript object that tracks bill amount, tip percentage, and split count, triggering real-time DOM updates via event listeners. CSS custom properties and flexbox layouts ensure a responsive, modern dark-mode interface with smooth transitions. Input validation and calculation logic are encapsulated in modular functions to maintain clean separation of concerns and facilitate future scalability.
