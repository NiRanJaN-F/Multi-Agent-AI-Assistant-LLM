## Overview

Build a SaaS task management app with user authentication, team workspaces, kanban board, and real-time updates using Express + HTML/JS.

## Tech Stack

Node Express+HTML/JS

The backend is an Express server with a PostgreSQL (via Sequelize) data layer modeling Users, Workspaces, Boards, and Cards. JWT middleware secures REST APIs for authentication, workspace, board, and card CRUD operations. Socket.io is attached to the HTTP server to broadcast board and card changes in real‑time to all clients in a workspace. The frontend is static HTML/JS served from the public folder, using vanilla JS to call the APIs and listen to Socket.io events, rendering a simple Kanban UI.

## Implementation Plan

- Initialize Node project, install Express, Socket.io, and set up static HTML/JS serving.
- Implement JWT‑based user authentication (register, login, middleware).
- Create workspace and kanban board REST APIs with CRUD operations and relational data model.
- Add real‑time board updates via Socket.io and integrate front‑end UI to consume APIs.
