## Tech Stack

React+Vite+CSS

A minimalist, client-side React counter application built with Vite for optimal performance and fast development feedback. State is managed locally via React hooks within a dedicated Counter container component, ensuring clean unidirectional data flow down to presentation controls. Modern responsive styling is implemented using custom CSS variables, flexbox alignment, and interactive hover state transitions.
