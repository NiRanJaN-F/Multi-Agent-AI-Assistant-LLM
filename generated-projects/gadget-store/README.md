## Overview

Build a modern e-commerce store with shopping cart

## Tech Stack

React+Vite+Node Express+MongoDB

The application is organized as a monorepo separating the Vite‑powered React frontend and the Express API backend, both sharing a root package.json for workspace scripts. MongoDB stores product documents and cart items, with Mongoose models encapsulating schema logic. The frontend communicates with the backend via a concise REST API for product retrieval and cart manipulation, while React components render the catalog and cart UI. This separation enables independent scaling, clear responsibility boundaries, and fast development cycles.

## Implementation Plan

- Initialize fullstack monorepo with Vite frontend and Express backend
- Design MongoDB schemas for products and cart items
- Implement REST endpoints for product listing and cart management
- Build React UI components and integrate with backend API
