## Overview

Build a SaaS task management app with user authentication, team workspaces, kanban board, and real-time updates using Express + HTML/JS.

## Tech Stack

Node.js + Express + HTML/JS/CSS + SQLite + WebSockets

A monolithic real-time SaaS task management application powered by Node.js, Express, and SQLite. Authentication is handled via JWT middleware protecting workspace and kanban routes. Real-time updates across multiple clients are synchronized via native WebSockets integrated directly into the HTTP server instance.

## Implementation Plan

- Set up Express server, SQLite database schema for users, workspaces, and tasks, and WebSocket integration for real-time updates.
- Implement user authentication (JWT signup/login) and workspace management middleware.
- Develop Kanban board backend routes for task CRUD operations and state transitions.
- Create frontend HTML/JS interface with real-time UI synchronization via WebSockets.
