## Overview

Build a modern SaaS landing page with hero section, features grid, testimonials, pricing table, and contact form with full CSS animations.

## Tech Stack

React+Vite+CSS

This architecture leverages React and Vite with a modular component structure supported by a centralized CSS variables styling system. Key sections such as the Hero, Features, Testimonials, Pricing, and Contact form are isolated into dedicated components for optimal maintainability. Full CSS animations, entrance keyframes, and responsive media queries are integrated directly into the stylesheet to ensure a high-performance modern SaaS user experience.

- Build responsive Navigation and Hero section with CSS entrance animations
- Implement Features grid, Testimonials carousel, and Pricing table components
