## Overview

Build a full-stack e-commerce store with product listings, a shopping cart, and checkout flow using Express backend and interactive HTML/JS frontend.

## Tech Stack

Node.js Express + HTML/CSS/JS

The architecture follows a classic MVC pattern with Express handling routing and a lightweight in‑memory data store for products and cart items. The frontend is a single‑page application served from the public folder, using vanilla JS to fetch data from REST endpoints and manipulate the DOM. All API routes are prefixed with /api and return JSON payloads with a success flag and data payload, enabling easy error handling on the client side. The component tree is flat, keeping the UI simple while still separating concerns for header, product list, cart, checkout, and footer.
