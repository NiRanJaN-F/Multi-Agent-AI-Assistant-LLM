# Personal Finance Tracker

> Generated by the Multi-Agent AI Software Engineering Assistant.

## Overview

Build a personal finance tracker with income/expense logs, category breakdown, and monthly budget summary

## Tech Stack

React+Vite+Node+Express+SQLite

A full-stack personal finance tracker utilizing React with Vite and Tailwind CSS on the frontend, communicating via Axios with a Node.js and Express backend. Data persistence is handled by a lightweight SQLite database storing transactions and budget configurations. The application features real-time category breakdown aggregations and dynamic monthly summary dashboards.

## Implementation Plan

- Set up Node.js Express backend with SQLite database and API endpoints for transactions and budgets
- Build React frontend with Vite, Tailwind CSS, and Axios for API integration
- Implement income/expense logging form and transaction history table
- Create category breakdown charts and monthly budget summary dashboard
