## Overview

Build a full-stack e-commerce store with product listings, a shopping cart, and checkout flow using Express backend and interactive HTML/JS frontend.

## Tech Stack

Node.js Express + Vanilla HTML/CSS/JS

This architecture employs a lightweight Node.js Express backend serving static HTML/CSS/JS files alongside RESTful JSON endpoints for product management and checkout. The frontend uses vanilla JavaScript with reactive state management to handle product filtering, a dynamic shopping cart, and a multi-step checkout flow. In-memory data structures mock the database for seamless local execution and fast prototyping.

## Implementation Plan

- Set up Express server with static file serving and product data endpoints
- Implement product listing and filtering view in frontend HTML/JS
- Create interactive shopping cart state management in client-side JavaScript
- Build mock checkout flow with order confirmation handling
