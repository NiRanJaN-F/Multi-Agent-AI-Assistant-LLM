# Food Delivery App

> Generated by the Multi-Agent AI Software Engineering Assistant.

## Overview

Build a modern dark-mode Food Delivery web app with menu items (Pizza, Burger, Sushi), an interactive add-to-cart counter, dynamic bill total with tax/delivery, and a checkout order modal.

## Tech Stack

Vanilla HTML/CSS/JavaScript

The application uses a lightweight Node.js/Express backend to serve static files and expose a REST API for menu items. The front‑end is built with vanilla HTML, CSS, and JavaScript, leveraging CSS variables for dark‑mode toggling and localStorage for cart persistence. Menu items are fetched from the API and rendered dynamically, with an interactive add‑to‑cart counter that updates a bill total including tax and delivery fees. A modal checkout form summarizes the order and confirms the purchase, all while maintaining responsive design and basic accessibility.
