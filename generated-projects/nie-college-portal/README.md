## Overview

Build a full-stack NIE college website  with department listing , courses, and academics and placements  using Express backend and interactive HTML/JS frontend.

## Tech Stack

Node Express + Vanilla JS/HTML/CSS

This architecture utilizes a lightweight Node.js and Express backend serving RESTful JSON APIs for college data (departments, courses, academics, placements). The frontend is built using Vanilla HTML, CSS, and JavaScript, leveraging client-side AJAX (Fetch API) to dynamically render interactive views and dashboards. CORS and JSON middleware are integrated in the backend to ensure seamless communication and data exchange between server and client.

## Implementation Plan

- Initialize Node.js Express backend with CORS and JSON middleware
- Create REST endpoints for departments, courses, academics, and placements
- Develop interactive frontend HTML/CSS/JS dashboard with dynamic views
- Implement client-side AJAX requests to fetch and render college data
