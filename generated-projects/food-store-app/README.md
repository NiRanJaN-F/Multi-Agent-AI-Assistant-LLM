## Overview

Build a full-stack food store with product listings, a shopping cart, and checkout flow using Express backend and interactive HTML/JS frontend.

## Tech Stack

Node Express + Vanilla JS / HTML / CSS

This full-stack food store application uses a Node.js Express backend serving a static vanilla HTML/JS single-page frontend. The server provides RESTful API endpoints for retrieving the product catalog and processing checkout orders with JSON payloads. The interactive frontend manages client-side shopping cart state and communicates with the backend via fetch API requests.

## Implementation Plan

- Initialize Express server with JSON middleware and static file serving for the frontend.
- Implement backend API routes for product catalog retrieval and order checkout processing.
- Build interactive frontend UI with product listing grid and dynamic shopping cart sidebar.
- Connect frontend cart state and checkout form submission to the Express API endpoints.
