## Overview

build a chess board just ui with 8*8 board ui using html css

## Tech Stack

Vanilla HTML + CSS

The architecture is a purely static frontend implementation leveraging CSS Grid to render an 8x8 chessboard layout without any JavaScript or backend dependencies. The HTML structure uses semantic divs for the board container and individual squares, while CSS handles alternating colors, fixed dimensions, and responsive scaling via viewport units. Board coordinates and hover effects are implemented entirely through CSS pseudo-elements and transitions to enhance user experience. Since the application is UI-only, no API endpoints or server-side components are required.
